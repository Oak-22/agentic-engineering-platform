# Routing Fixtures

These examples are replayable contract specimens, not records of live
destination mutations.

- `append-to-existing-implementation-record/` shows a small follow-up being
  consolidated into an existing outcome boundary instead of generating Jira
  or Confluence work.
- `exact-duplicate-suppression/` shows a repeated delivery returning the
  original receipt without changing destination state twice.
- `semantic-loop-suppression/` shows different events with the same normalized
  intent being stopped before a repeated external write.
