# General Agent Guidance

Apply these rules to every repository task:

- Read the applicable repository guidance and nearest component documentation
  before changing ownership boundaries or architecture.
- Preserve user-authored and unrelated work.
- Keep changes scoped, use existing patterns, and run the smallest relevant
  verification.
- Treat generated artifacts as derived output and verify them against their
  canonical source.
- Never commit credentials, private knowledge overlays, or machine-specific
  paths.
- Report assumptions, unverified results, residual risk, and the next
  unapproved delivery gate.
