# Operations

Migration records, runbooks, and repository operating procedures belong here.

## Repository delivery

- [Governed Repository Delivery](governed-repository-delivery.md) is the
  human-facing entrypoint for moving continuous workbench changes into bounded
  Jira and GitHub delivery units.
- [Workbench-to-Delivery Branching](../../platform/agent-control-plane/docs/workbench-delivery-branching.md)
  defines the detailed Git topology, transfer rules, worktree exceptions, and
  cleanup invariants behind that operating model.
