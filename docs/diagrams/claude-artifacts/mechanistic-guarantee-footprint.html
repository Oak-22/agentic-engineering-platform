Agent Control Plane — Governance Model, Conceptual Goal

Grow the mechanistic core

Not the current state — the target. Each ring narrows in scope the way deep learning sits inside machine learning inside artificial intelligence: every inner category is a stricter subset of the one around it. Right now the solid core — the part with an actual mechanical guarantee, not just a stated rule — is small and limited to hooks. The goal is to grow that core outward, into role-charters and the structurally-checkable parts of execution-policies, without pretending judgment calls can be mechanized away entirely.

What "growing the core" would actually require

  1. Role charters — bind identity, not just document it
    Today a charter states who's accountable in prose. A mechanized version would tie a charter to something checkable at runtime — a required approver on the record, not just named in a document.
  2. Execution policies — mechanize the checkable slice
    Authorization ("did the user actually say this") stays a judgment call. But evidence presence — a linked pull request, a citation, a re-read confirmation — is structurally checkable, and could gate completion the way a hook gates a commit.
  3. Leave the outer ring alone
    Instructions and skills exist precisely because not everything should be mechanized. Growing the core means shrinking the gap identified for policies and charters — not erasing the interpretive layer entirely.
